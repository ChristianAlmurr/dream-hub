# Memory index — one line per file. Read this, then grep only what you need.

- `ORG.md`: principles and non-negotiables (read every task)
- `project/architecture.md`: how the code base is laid out, key entry points
- `project/gotchas.md`: known traps, failing tool configs and their fixes
- `project/decisions.md`: decisions taken and why (short ADR-style lines)
- `agents/<name>/scratch.md`: per-agent working notes (ephemeral)
- `inbox/`: proposals waiting for dreaming or human review
- `dreams/`: dream reports (proposed changes + evidence)
